# Inter fonts

Unmodified variable WOFF2 assets from the TNotes.electron VitePress deployment (2026-09-04), covering normal/italic weights 100–900 and all seven deployed Unicode subsets. Content-hash suffixes were removed from filenames; Vite adds its own hashes when bundling.

- Font: [Inter](https://github.com/rsms/inter), by the Inter Project Authors.
- Source manifest: https://tnotesjs.github.io/TNotes.electron/assets/style.CvuHcqLd.css
- License: SIL Open Font License 1.1, preserved in `src/renderer/public/licenses/Inter.txt` and copied into the packaged renderer.
- Font-face declarations and Chinese punctuation fallbacks are in `../../fonts.css`.

No runtime network access or system installation is required for Inter. Chinese glyphs use system sans-serif fonts, as in VitePress.
