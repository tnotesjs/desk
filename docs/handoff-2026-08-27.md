### 5.1 mindmap 居中（已根因定位 + 已实测修复验证）

**现象**：```mindmap 能渲染出 学习计划→前端/后端，但初始不居中（偏右下、内容出画布），需拖动才进视野。

**根因（实证，非 zoomToFit 时序问题）**：

- 宿主 `.desk-diagram__mindmap` 尺寸 693×320，`overflow:hidden`，clientWidth=693、**scrollWidth=1386**（内容溢出）。
- canvas `.mm-canvas`：**bitmap 和 CSS 尺寸都是 1386×640 = 宿主×2**（`window.devicePixelRatio=2`），`position:static`、`transform:none`、offset 起点=宿主内容原点。
- 内容在 canvas **位图内已居中**：像素 bbox (449,211)-(937,403)，bbox 中心 (693,307) vs 画布中心 (693,320)，水平偏差 0、垂直仅 -13（2%）。
- 所以 `zoomToFit` 在**位图坐标系**里居中是成功的；但 canvas 元素以 2 倍尺寸渲染、被宿主 `overflow:hidden` 裁成 693×320，可见区只显示 canvas **左上角**，而内容中心 (693,307) 恰在可见区右缘/下缘 → 用户只看到右下角的根节点，子树被裁掉。

**修复（@tnotesjs/mindmap-core `resize()`，dist/index.js:1433-1434）**：

```js
// 原：只设位图尺寸 = clientWidth*devicePixelRatio，未设 style，canvas 元素继承 intrinsic=2×宿主
this.canvas.width = Math.max(1, Math.round(t * e))
this.canvas.height = Math.max(1, Math.round(n * e))
// 补：把元素 CSS 尺寸钉回宿主 client 尺寸，位图仍为 dpr 高清（或另加 .mm-canvas{width:100%;height:100%} 样式规则）
this.canvas.style.width = `${t}px`
this.canvas.style.height = `${n}px`
```

**已验证**：临时 patch node_modules 该 dist + `pnpm exec electron-vite build` 后重跑 E2E——宿主 scrollWidth 变回 693（不再溢出）、canvas cssSize 变回 693×320、树完整居中显示（截图为证）。

## 8. 运行态 E2E 自测（本会话实测打通，Playwright Electron）

**用途**：驱动真实的 desk 窗口、打开笔记、截图、像素级断言——补上「单测/ happy-dom 跑不了布局」与「看不到画面」两块缺口。适合 mindmap 居中回归、desk-032 高亮复现、以及任意需要「真 UI 表现」的验证。

**前置**：

- `desk` 已 `pnpm exec electron-vite build`（out/ 须与 src 同步，脚本跑的是 out/ 产物）。
- 已 `pnpm add -D playwright-core`（只装 core，不下载浏览器，用 desk 自带 electron）。

**脚本**：`scripts/e2e-mindmap.mjs`，模式：

- `--probe`：启动 → 截图主窗口 → 输出页面文本（探 UI 结构）。
- `--docs`：点 docs 知识库 → 截图笔记列表。
- `--mindmap`：点 docs → 打开 0041 笔记 → 定位 `.desk-diagram__mindmap canvas` → 输出 **像素级居中分析**（host/canvas 尺寸、溢出、内容 bbox 中心 vs 画布中心偏移）→ 存 `scripts/shots/03-mindmap.png`。

**运行**：

```bash
cd desk
pnpm exec electron-vite build            # 同步 out/ 与 src
node scripts/e2e-mindmap.mjs --mindmap   # 会短暂弹出 desk 窗口
```

**关键实现点**：

- `_electron.launch({ executablePath: require('electron'), args: ['out/main/index.js', '--user-data-dir=/tmp/desk-e2e-profile'] })` —— 用独立 userData 避开单实例锁，并预写 `/tmp/desk-e2e-profile/workspace.v1.json = {"path":".../desk/playground"}`。
- 居中判定（程序化，不依赖视觉）：读 canvas 位图像素，求非背景像素 bbox，比较 bbox 中心与画布中心；再叠 context 的 `host.clientWidth/Height` 与 `canvas.style/ScrollWidth`，即可判「内容在可见区是否居中」。
